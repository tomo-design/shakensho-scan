
### 詳しい説明（4000文字以内）
```
メカノAIは、自動車・トラック整備士のための現場サポートアプリです。
車検証を読み取るだけで、その車両に必要な整備情報をAIがまとめて表示します。

■ 主な機能
・車検証スキャン：QRコード／写真から車両情報を自動読み取り
・メンテナンス諸元：エンジンオイル量・ミッション/デフオイル・クーラント量・推奨粘度・ホイールナット/ハブベアリングナット/アクスルフランジの締付トルク・打刻位置などをAIが取得
・AI故障診断：症状やDTC（故障コード）から想定原因・点検ポイントを提示
・修理サポート：作業名を入れるだけで取り付け位置・所要時間・部品注文リスト・手順・トルクを表示
・整備カルテ：作業記録を写真付きで保存
・リコール確認：型式・車台番号から届出情報の確認導線
・FAINES連携：正式な整備手順・品番・トルクの確認へワンタップ

■ こんな方に
・調べもの（諸元・トルク・粘度）に時間を取られている整備士
・若手・応援スタッフの即戦力化をしたい工場
・トラック〜乗用車まで幅広く扱う整備現場

■ ご注意
・AIの回答・部品番号は参考情報です。注文・作業前に必ず整備書（FAINES等）・メーカー資料・部品商で正式値をご確認ください。
・カメラで撮影した画像は、文字認識・整備情報の取得のためAI（Google Gemini）に送信して処理されます。詳しくはプライバシーポリシーをご覧ください。

■ 料金
・個人版は無料でご利用いただけます（一部機能はご自身のAPIキー設定が必要な場合があります）。
```

## 3. データセーフティ（Data safety）フォームの回答例

- **データ収集の有無**：あり（限定的）
- 収集/共有するデータ：
  - 「写真」→ 目的：アプリの機能（文字認識・整備情報取得）。**第三者（Google Gemini API）で処理**。端末外に送信されるが当社サーバーには保存しない旨を記載。
  - 「その他（車両情報：型式・車台番号等）」→ 目的：アプリの機能。ログイン利用時のみクラウド（Firebase）に保存。
- **データは暗号化して送信**：はい（HTTPS）
- **データ削除のリクエスト**：可（メール窓口）
- 広告：**なし**
- 位置情報・連絡先・金融情報：**収集なし**

※ 実際の設問はPlay Consoleの案内に沿って上記趣旨で回答してください。

## 5. 提出フロー（PWABuilder方式・Mac不要）

1. **Google Play Developer アカウント作成**（$25・一回のみ）
   https://play.google.com/console/signup

2. **AAB（アプリ本体）を生成**
   - https://www.pwabuilder.com/ を開く
   - URLに `https://mechanoai-cablueie.com/` を入力 → Start
   - スコアを確認して **Package For Stores → Android** を選ぶ
   - Package ID（applicationId）は **`com.cablueie.mechanoai`**（assetlinks.jsonと一致必須）
   - **Generate** → zipをダウンロード（`.aab` と署名鍵 `signing.keystore`＋`signing-key-info` が入っている）
   - ⚠️ **署名鍵とパスワードは絶対に紛失しないよう厳重保管**（次回更新に必須。無くすと更新不可）

3. **SHA256指紋を assetlinks.json に反映（重要）**
   - zip内の `assetlinks.json`（または `signing-key-info.txt`）に **SHA256フィンガープリント** が記載されています。
   - その値を私に送ってください → 私が `/.well-known/assetlinks.json` を更新して再デプロイします。
   - これをしないと、アプリ起動時に**アドレスバーが表示されたまま**になります（＝ただのブラウザに見える）。
   - ※ Play App Signingを使う場合は、**Play Console の「アプリの完全性 → アプリ署名」に表示されるSHA-256**（Google管理の署名鍵）を使うのが正解です。こちらも私に送ってください。

4. **Play Console でアプリ作成 → 情報入力**
   - 上記1〜4章のテキスト・画像・Data safety・レーティングを登録
   - プライバシーポリシーURLを設定

5. **AABをアップロード → 内部テスト → 製品版へ**
   - まず「内部テスト」で自分の端末に入れて動作確認するのがおすすめ
   - 問題なければ製品版リリースを申請 → 審査（通常数時間〜数日）
