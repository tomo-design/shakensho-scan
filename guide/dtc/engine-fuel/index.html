エンジン・燃料・空気量系の故障コード一覧

エアフロ・O2センサ・水温センサ・インジェクタ・燃圧など、燃料と空気の計量まわりで出るコードです。全21件。考えられる原因と、現場で確認する順番の目安です。

P0011 カム角タイミング進角過多/応答不良(バンク1)

オイル劣化・油圧不足によるVVT作動不良、OCV(オイルコントロールバルブ)詰まり・固着、タイミングチェーン伸び

P0011の詳しいページ

P0016 クランク/カム角センサ相関異常

考えられる原因: タイミングチェーン/ベルトのコマずれ・伸び、カム角・クランク角センサ不良、VVT機構不良

確認する順番: 1. 相関波形・データモニタ → 2. チェーンテンショナー → 3. センサ波形

P0016の詳しいページ

P0087 燃料レール圧力低すぎ

サプライポンプ(高圧ポンプ)不良、燃料フィルタ詰まり・エア噛み、プレッシャリミッタ開弁・リーク

P0087の詳しいページ

P0088 燃料レール圧力高すぎ

考えられる原因: SCV(吸入調量弁)固着、レール圧センサ不良、プレッシャリミッタ不良

確認する順番: 1. SCV作動・抵抗 → 2. レール圧センサ特性 → 3. 高圧系配管

P0088の詳しいページ

P0093 燃料系統大リーク検出

燃料配管・インジェクタシールからのリーク、プレッシャリミッタ開弁、サプライポンプ内部リーク

P0093の詳しいページ

P0101 エアフロセンサ範囲/性能異常

考えられる原因: エアフロ汚損、吸気漏れ(二次空気)、エアクリ詰まり

確認する順番: 1. エアフロ実測値(アイドル/レーシング) → 2. 吸気系の亀裂・抜け → 3. センサ清掃または交換

P0101の詳しいページ

P0102 エアフロセンサ信号低

考えられる原因: エアフロ故障・コネクタ接触不良、配線断線、吸気系の極端な詰まり

確認する順番: 1. コネクタ・配線導通 → 2. センサ電源電圧 → 3. 実測値

P0102の詳しいページ

P0113 吸気温センサ信号高(断線系)

考えられる原因: センサ断線・コネクタ外れ、配線不良

確認する順番: 1. コネクタ → 2. センサ抵抗値(温度特性)

P0113の詳しいページ

P0117 水温センサ信号低(短絡系)

考えられる原因: センサ内部短絡、ハーネス被覆破れの地絡

確認する順番: 1. センサ抵抗値 → 2. ハーネス点検

P0117の詳しいページ

P0118 水温センサ信号高(断線系)

考えられる原因: センサ断線、コネクタ接触不良

確認する順番: 1. コネクタ → 2. 抵抗値・データモニタの水温値

P0118の詳しいページ

P0120 スロットルポジションセンサ系統異常

考えられる原因: TPS/スロットルボディ不良、配線・コネクタ、カーボン堆積による全閉学習ズレ

確認する順番: 1. スロットル開度データ → 2. スロットル清掃+学習 → 3. 配線

P0120の詳しいページ

P0128 サーモスタット系統(水温上がらず)

考えられる原因: サーモスタット開きっぱなし、水温センサ特性ズレ

確認する順番: 1. 暖機後の実水温 → 2. サーモスタット交換歴

P0128の詳しいページ

P0130 O2センサ系統異常(B1S1)

考えられる原因: O2/AFセンサ劣化、ヒーター回路不良、排気漏れ

確認する順番: 1. センサ波形・応答性 → 2. ヒーター抵抗 → 3. エキマニ周り排気漏れ

P0130の詳しいページ

P0133 O2センサ応答遅い(B1S1)

考えられる原因: センサ劣化、燃調の濃い/薄い状態が継続、排気漏れ

確認する順番: 1. 波形の反転速度 → 2. 燃料トリム値 → 3. 吸排気漏れ

P0133の詳しいページ

P0135 O2センサヒーター回路異常(B1S1)

考えられる原因: ヒーター断線、ヒューズ・リレー、配線

確認する順番: 1. ヒーター抵抗値 → 2. 電源系 → 3. コネクタ

P0135の詳しいページ

P0171 燃調リーン(薄い)バンク1

吸気漏れ(インマニ・ホース)、エアフロ汚損で空気量過少表示、燃圧不足・インジェクタ詰まり、PCVバルブ系リーク

P0171の詳しいページ

P0172 燃調リッチ(濃い)バンク1

考えられる原因: インジェクタリーク、燃圧過大(レギュレータ)、エアフロ特性ズレ、O2センサ不良

確認する順番: 1. プラグの状態(かぶり) → 2. 燃圧 → 3. インジェクタバランス

P0172の詳しいページ

P0191 燃料レール圧センサ性能異常

考えられる原因: レール圧センサ特性ズレ、配線、実圧力異常との切り分け要

確認する順番: 1. IG ONとアイドルのセンサ値 → 2. 配線 → 3. P0087/P0088併発確認

P0191の詳しいページ

P0201 インジェクタ回路異常(1番気筒) ※P0202〜P0208は2〜8番

考えられる原因: インジェクタ断線・短絡、ハーネス・コネクタ、EDU/ECU駆動系

確認する順番: 1. インジェクタ抵抗値 → 2. 駆動波形 → 3. 該当気筒の入れ替えテスト

P0201の詳しいページ

P0234 過給圧過大(オーバーブースト)

考えられる原因: 可変ノズル(VNT)固着、ウェイストゲート/アクチュエータ不良、ブーストセンサ

確認する順番: 1. ブースト実測値 → 2. VNTリンクの動き → 3. アクチュエータ作動

P0234の詳しいページ

P0299 過給圧不足(アンダーブースト)

考えられる原因: ブーストホース抜け・亀裂、タービン不良・羽根損傷、インタークーラー漏れ、VNT固着

確認する順番: 1. 加圧テストで漏れ探索 → 2. タービン軸ガタ・オイル漏れ → 3. ブーストデータ

P0299の詳しいページ
