排気・後処理系（EGR・触媒・DPF・尿素SCR）の故障コード一覧

EGR・触媒・EVAP・DPF/DPD/DPR・尿素SCRなど、排気と後処理まわりで出るコードです。大型車で多く見るコードもここに入ります。全20件。考えられる原因と、現場で確認する順番の目安です。

P0401 EGR流量不足

EGRバルブ・通路のカーボン詰まり、EGRバルブ作動不良、EGRクーラー詰まり

P0401の詳しいページ

P0402 EGR流量過大

考えられる原因: EGRバルブ閉じ側固着・密着不良、ポジションセンサずれ

確認する順番: 1. 全閉位置データ → 2. バルブ清掃・交換

P0402の詳しいページ

P0404 EGRバルブ開度異常

考えられる原因: バルブ固着(カーボン)、モーター/ポジションセンサ不良

確認する順番: 1. アクティブテストで開閉 → 2. 目標開度と実開度の乖離

P0404の詳しいページ

P0420 触媒劣化(バンク1)

考えられる原因: 触媒劣化・溶損、リア O2センサ劣化(誤検出)、失火・オイル上がりによる被毒

確認する順番: 1. 前後O2波形比較 → 2. 失火・オイル消費の有無 → 3. 触媒温度

P0420の詳しいページ

P0441 EVAPパージ流量異常

考えられる原因: パージVSV不良、配管詰まり・抜け、チャコールキャニスタ

確認する順番: 1. VSV単体作動 → 2. 配管経路 → 3. 給油キャップ

P0441の詳しいページ

P2002 DPF/DPR/DPD 捕集効率低下(バンク1)

フィルタ溶損・破損、差圧センサ・配管詰まり、強制再生の繰り返しによる灰分蓄積

P2002の詳しいページ

P2096 燃調リーン(触媒後)

考えられる原因: 排気漏れ、リアO2センサ、燃料系

確認する順番: 1. 排気系目視 → 2. 燃料トリム

P2096の詳しいページ

P2101 電子スロットルモーター系統異常

考えられる原因: スロットルボディ不良・カーボン固着、配線

確認する順番: 1. スロットル清掃+全閉学習 → 2. モーター抵抗

P2101の詳しいページ

P2122 アクセルポジションセンサ信号低(D系統)

考えられる原因: APS不良、コネクタ・配線

確認する順番: 1. ペダル開度データ2系統比較 → 2. 配線

P2122の詳しいページ

P2138 アクセルポジションセンサ相関異常

考えられる原因: APS不良、コネクタ接触不良(水入り)

確認する順番: 1. 2系統の電圧特性 → 2. コネクタ端子

P2138の詳しいページ

P2146 インジェクタ電源グループ回路異常

考えられる原因: インジェクタハーネス短絡、EDU/インジェクタドライバ不良

確認する順番: 1. グループ内インジェクタ抵抗 → 2. ハーネス擦れ → 3. EDU出力

P2146の詳しいページ

P2196 O2センサ信号リッチ張り付き

考えられる原因: インジェクタリーク、燃圧過大、エアフロ

確認する順番: 1. 燃料トリム → 2. プラグかぶり → 3. 燃圧

P2196の詳しいページ

P2227 大気圧センサ性能異常

考えられる原因: ECU内蔵大気圧センサ、配管(外付けの場合)

確認する順番: 1. 他の圧力センサとの比較値

P2227の詳しいページ

P2263 ターボブースト性能異常

考えられる原因: VNT固着、ブーストリーク、EGR大量リーク

確認する順番: 1. ブースト実測 → 2. アクチュエータ作動 → 3. 吸気系加圧テスト

P2263の詳しいページ

P2453 DPF差圧センサ性能異常

考えられる原因: 差圧配管の煤詰まり・抜け、センサ特性ズレ

確認する順番: 1. 配管清掃 → 2. IG ON時のゼロ点 → 3. アイドル/レーシング差圧

P2453の詳しいページ

P2463 DPF煤過剰堆積

短距離走行で再生不足、インジェクタ不調で煤過多、再生インターバル短縮の根本原因あり

P2463の詳しいページ

P20EE SCR NOx触媒効率低下

尿素水の品質・濃度不良、尿素インジェクタ詰まり、NOxセンサ劣化、SCR触媒劣化

P20EEの詳しいページ

P207F 尿素水品質異常

考えられる原因: 規格外尿素水・希釈、NOxセンサ誤検出、SCRシステム不良

確認する順番: 1. 尿素水を新品規格品に入替 → 2. リセット後の再発確認 → 3. NOxセンサ

P207Fの詳しいページ

P204F SCRシステム性能異常

考えられる原因: 尿素ポンプ・配管詰まり(結晶)、ドージングバルブ、DCU

確認する順番: 1. 尿素ライン圧力 → 2. 噴射テスト → 3. 配管の結晶化

P204Fの詳しいページ

P0471 排気圧センサ性能異常

考えられる原因: センサ配管煤詰まり、センサ不良

確認する順番: 1. 配管清掃 → 2. データ確認

P0471の詳しいページ
